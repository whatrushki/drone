# GEOSCAN FleetCommander AI
**Интеллектуальный сервис планирования и распределения беспилотных авиационных работ для группы БВС**

> Разработано в рамках хакатона «Лидеры Цифровой Трансформации 2026» для компании **АО «Геоскан»**.

---

## 🌟 Ключевые преимущества и инновации решения

1. **Реалистичная физика и кинематика линейки БВС Геоскан**:
   - **Геоскан 201 (Самолет / Крыло)**: моделирование крейсерского полета (21 м/с), минимального радиуса виража (85 м) по **дугам Дубинса (Dubins Paths)** с выносными петлями (bulb turns) за пределы полигона, учет посадки на парашюте против ветра.
   - **Геоскан Gemini / 801 (Мультироторы)**: вертикальный взлет/посадка (VTOL), локальные развороты, повышенный учет энергопотребления при ветре.
2. **Аэродинамический навигационный треугольник скоростей (Wind Vector Triangle)**:
   - Вектор ветра $\vec{W}$ раскладывается на путевую скорость $V_{\text{ground}}$ и угол упреждения сноса (Crab angle).
   - Автоматический выбор оптимального азимута галсов вдоль направления ветра для минимизации крена и сноса камеры.
3. **Ответ на прямой вызов ТЗ: Стандарт 4D-Airspace**:
   - Внедрен открытый стандарт описания пространственно-временных ограничений (4D GeoJSON) с автоматическим парсером эшелонов FL, высот AGL/AMSL и временных окон NOTAM.
4. **Многокритериальная оптимизация**:
   - **Минимум времени (Makespan)**: параллельная нарезка и распределение галсов между разнородным флотом пропорционально их скорости.
   - **Минимум налета (Resource Saving)**: минимизация износа парка с приоритетом самого энергоэффективного борта.
5. **Интеллектуальная СППР (Feasibility & Operational Advisor)**:
   - Прямой ответ на требования заказчика (Геоскан): интерактивная проверка выполнимости задания по времени (конец светового дня / режим) и размеру флота.
   - Сравнение сценариев: «1 борт (минимум холостых перелетов и ТО)» против «Параллельного флота (экспресс-режим)».
   - Автоматический учет официальных нормативов регламентного ТО Геоскана (201/401 — 80 полетов, 501/801 — 160 ч, 701 — 100 моточасов).
6. **3D Пространственная безопасность и обход препятствий (STRtree R-Tree)**:
   - Мгновенная фильтрация 8 363 высотных вышек (Московская область + Приморский край) и 341 зоны ограничений за **< 1 мс**.
   - Физический контроль GSD: если рабочая высота съемки ниже вышки, набор высоты запрещен (ухудшение разрешения GSD) — система автоматически вырезает буфер безопасности 70 м и прокладывает обходные галсы.
7. **Контроль воздушного законодательства РФ (ПП РФ № 138)**:
   - Мониторинг высотного порога 150 м AGL с автоматическим предупреждением о необходимости подачи плана полета (FPL) в зональный центр ЕС ОрВД.
8. **4D Time-Lapse симуляция полета**:
   - Интерактивный плеер на веб-карте, показывающий синхронное движение бортов, контроль безопасности и статус каждого дрона в воздухе.
9. **Экспорт во все отраслевые форматы**:
   - KML (Google Earth / Geoscan), GeoJSON, QGroundControl / Mission Planner (`.plan`).

## 🚀 Инструкция по быстрому запуску

### Требования
* Python 3.10+ (протестировано на Python 3.13)
* Браузер Chrome / Firefox / Edge

### Установка зависимостей
```bash
pip install fastapi uvicorn shapely geopandas pyproj scipy numpy pydantic
```

### Запуск сервиса
```bash
python run.py
```

После запуска откройте в браузере:
* **Веб-интерфейс**: [http://localhost:8000](http://localhost:8000)
* **Интерактивная документация Swagger API**: [http://localhost:8000/docs](http://localhost:8000/docs)

## 📐 Математический аппарат

### 1. Фотограмметрия
$$H = \frac{F \cdot GSD}{s_p}, \quad D_{\text{swath}} = W_{\text{ground}} \cdot (1 - p_{\text{side}}), \quad B_x = L_{\text{ground}} \cdot (1 - p_{\text{forward}})$$

### 2. Вектор ветра
$$\vec{V}_{\text{ground}} = \vec{V}_{\text{air}} + \vec{W}, \quad \sin(\delta) = -\frac{W_{\text{cross}}}{V_{\text{air}}}$$

### 3. Радиус виража Дубинса для Геоскан 201
$$R_{\min} = \frac{V_{\text{air}}^2}{g \cdot \tan(\phi_{\max})} \approx 85\text{ м}$$

## 📋 Описание REST API
* `GET /api/catalog` — Справочник ТТХ БВС, камер и сенсоров.
* `GET /api/parcels` — Список участков из `Границы полетов.kml`.
* `GET /api/parcels/{fid}` — GeoJSON участка по его FID.
* `GET /api/airspace-zones` — 4D-зоны ограничений с высотами.
* `GET /api/obstacles` — Высотные мачты и вышки.
* `POST /api/preview-photogrammetry` — Мгновенный расчет высоты и шага съемки.
* `POST /api/plan-mission` — Полный расчет полетного задания для группы БВС.
* `POST /api/export/kml` — Выгрузка KML.
* `POST /api/export/geojson` — Выгрузка GeoJSON.
* `POST /api/export/qgc` — Выгрузка `.plan`.
